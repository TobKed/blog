Handling exceptions with contextlib.supress()

import contextlib

with contextlib.suppress(FileNotFoundError):
    os.remove("somefile.tmp")

This is equivalent to the following try/except clause:

try:
    os.remove("somefile.tmp")
except FileNotFoundError:
    pass
