{{- /* The cover for a page, or nothing. Context: a Page, or a dict of page, class, decorative and eager (skip loading="lazy", for the first cover). alt is the page's image_alt, else its title. decorative gives alt="" for repeats that sit right beside the title (back issues, the archive grid). When covers are hidden by default the URL is parked in data-src, because display:none does not stop a browser downloading an . theme.js promotes data-src to src if the reader turns photos back on. */ -}} {{- $page := . -}} {{- $class := "" }}{{ $decorative := false }}{{ $eager := false -}} {{- if reflect.IsMap . -}} {{- $page = .page -}} {{- $class = .class | default "" }}{{ $decorative = .decorative | default false }}{{ $eager = .eager | default false -}} {{- end -}} {{- $alt := cond $decorative "" ($page.Params.image_alt | default $page.Title) -}} {{- with partial "cover-url.html" $page -}} {{- end -}}
