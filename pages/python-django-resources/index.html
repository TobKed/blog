Books#

  • Flask Web Development - Miguel Grinberg: Hands-on guide to building web applications in Python using the Flask microframework.
  • Fluent Python - Luciano Ramalho: Deep dive into idiomatic Python, data model internals, and writing expressive Pythonic code.
  • Learning Python - Mark Lutz: Comprehensive reference covering core Python language fundamentals from the ground up.
  • Test-Driven Development with Python - Harry Percival: Free online book (“Obey the Testing Goat”) teaching TDD step by step with Python, Django, and Selenium.
  • Two Scoops of Django 1.11: Best Practices for the Django Web Framework - Daniel Roy Greenfeld, Audrey Roy Greenfeld: Practical patterns, conventions, and architectural best practices for building maintainable Django projects.

Podcasts#

  • Django Chat: Weekly podcast on the Django web framework hosted by Will Vincent and Carlton Gibson.
  • Import This: A Podcast for Humans: Conversational Python podcast hosted by Kenneth Reitz and Alex Gaynor.
  • IRL: Online Life is Real Life: Mozilla podcast exploring how technology, privacy, and AI shape life online and offline.
  • Piątki po deployu (PL): Polish-language software engineering podcast discussing backend development and tech culture.
  • Python Bytes: Short weekly podcast delivering Python headlines, package releases, and developer news by Michael Kennedy and Brian Okken.
  • Talk Python To Me: Long-form interviews with creators, maintainers, and practitioners across the Python ecosystem, hosted by Michael Kennedy.
  • Test & Code: Podcast by Brian Okken focused on Python testing, pytest, software engineering, and developer tooling.
  • The Real Python Podcast: Weekly conversations on Python programming, career growth, and best practices hosted by Christopher Bailey.

Videos#

  • PyVideo.org: Searchable index of thousands of recorded talks and tutorials from PyCon and regional Python conferences worldwide.

Blogs#

  • Adam Johnson: Prolific articles and tips on Django, Python testing, Git, and developer productivity by a Django Technical Board member.
  • Haki Benita: In-depth engineering posts on Django performance, PostgreSQL internals, SQL optimization, and Python.
  • Matt Layman: Practical guides and series (“Understand Django”) on building and deploying Django web applications.
  • Michał Klich: Personal engineering blog covering Python, backend development, and developer tools.
  • Miguel Grinberg Blog: Tutorials and deep dives on Flask, Python web development, async Python, and React.
  • The Digital Cat: Leonardo Giordani’s blog on Python OOP, clean architecture, TDD, and refactoring.
  • Will Vincent: Tutorials and guides on Django authentication, project setup, and best practices.

Tutorials#

  • Coding Entrepreneurs - YouTube Channel: Project-based video tutorials on Django, Python, REST APIs, and full-stack deployment.
  • Corey Schafer - YouTube Channel: Clear, comprehensive video series covering Python fundamentals, OOP, Django, Flask, Git, and SQL.
  • Dennis Ivy - YouTube Channel: Practical Django and Django REST Framework crash courses and full-project walkthroughs.
  • JustDjango - YouTube Channel: Video tutorials focused on building modern web applications with Django and frontend frameworks.
  • Real Python: Extensive library of step-by-step Python articles, tutorials, quizzes, and video courses.

Django#

  • Awesome Django: Curated list of awesome Django packages, articles, projects, and third-party resources.
  • Classy Class-Based Views: Interactive inspector showing every method, attribute, and MRO hierarchy for Django’s built-in class-based views.
  • Classy Django Forms: Detailed inspector for Django form classes, fields, and widgets modeled after Classy Class-Based Views.
  • Classy Django REST Framework: Browseable reference of methods and attributes for every class-based view and serializer in Django REST Framework.
  • Django Deconstructed: Breakdowns and explanations of how Django components work under the hood.
  • Django News: Weekly newsletter curating Django releases, articles, packages, tutorials, and community events.
  • Django Packages: Directory of reusable apps, sites, tools, and packages for Django projects with side-by-side comparisons.
  • Django Project: Official website, documentation, release notes, and community hub for the Django web framework.
  • Django Snippets: Community-contributed repository of reusable Django code snippets and patterns.
  • Forum Django Project: Official Discourse forum for Django users and core contributors.

Conferences & Meet-ups#

  • PyCon CZ: Annual community-organized Python conference in the Czech Republic.
  • PyCon PL: Annual Polish Python community conference featuring talks, workshops, and sprints.
  • PyWaw: Warsaw Python community meetup hosting regular technical talks and networking events.
