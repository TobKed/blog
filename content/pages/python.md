## Books

- **[Flask Web Development - Miguel Grinberg](http://shop.oreilly.com/product/0636920089056.do)**: Hands-on guide to building web applications in Python using the Flask microframework.
- **[Fluent Python - Luciano Ramalho](http://shop.oreilly.com/product/0636920032519.do)**: Deep dive into idiomatic Python, data model internals, and writing expressive Pythonic code.
- **[Learning Python - Mark Lutz](http://shop.oreilly.com/product/0636920028154.do)**: Comprehensive reference covering core Python language fundamentals from the ground up.
- **[Test-Driven Development with Python - Harry Percival](http://www.obeythetestinggoat.com/)**: Free online book ("Obey the Testing Goat") teaching TDD step by step with Python, Django, and Selenium.
- **[Two Scoops of Django 1.11: Best Practices for the Django Web Framework - Daniel Roy Greenfeld, Audrey Roy Greenfeld](https://www.roygreenfeld.com/collections/two-scoops-press/products/two-scoops-of-django-1-11)**: Practical patterns, conventions, and architectural best practices for building maintainable Django projects.

## Podcasts

- **[Django Chat](https://djangochat.com/)**: Weekly podcast on the Django web framework hosted by Will Vincent and Carlton Gibson.
- **[Import This: A Podcast for Humans](https://www.kennethreitz.org/import-this/)**: Conversational Python podcast hosted by Kenneth Reitz and Alex Gaynor.
- **[IRL: Online Life is Real Life](https://irlpodcast.org/)**: Mozilla podcast exploring how technology, privacy, and AI shape life online and offline.
- **[Piątki po deployu (PL)](https://soundcloud.com/user-290159543)**: Polish-language software engineering podcast discussing backend development and tech culture.
- **[Python Bytes](https://pythonbytes.fm/)**: Short weekly podcast delivering Python headlines, package releases, and developer news by Michael Kennedy and Brian Okken.
- **[Talk Python To Me](https://talkpython.fm/)**: Long-form interviews with creators, maintainers, and practitioners across the Python ecosystem, hosted by Michael Kennedy.
- **[Test & Code](https://testandcode.com/)**: Podcast by Brian Okken focused on Python testing, `pytest`, software engineering, and developer tooling.
- **[The Real Python Podcast](https://realpython.com/podcasts/rpp/)**: Weekly conversations on Python programming, career growth, and best practices hosted by Christopher Bailey.

## Videos

- **[PyVideo.org](https://pyvideo.org/)**: Searchable index of thousands of recorded talks and tutorials from PyCon and regional Python conferences worldwide.

- **[Will Vincent](https://wsvincent.com/)**: Tutorials and guides on Django authentication, project setup, and best practices.

## Django

- **[Awesome Django](https://github.com/wsvincent/awesome-django)**: Curated list of awesome Django packages, articles, projects, and third-party resources.
- **[Classy Class-Based Views](https://ccbv.co.uk/)**: Interactive inspector showing every method, attribute, and MRO hierarchy for Django's built-in class-based views.
- **[Classy Django Forms](https://cdf.9vo.lt/)**: Detailed inspector for Django form classes, fields, and widgets modeled after Classy Class-Based Views.
- **[Classy Django REST Framework](http://www.cdrf.co/)**: Browseable reference of methods and attributes for every class-based view and serializer in Django REST Framework.
- **[Django Deconstructed](https://djangodeconstructed.com/)**: Breakdowns and explanations of how Django components work under the hood.
- **[Django News](https://django-news.com/)**: Weekly newsletter curating Django releases, articles, packages, tutorials, and community events.
- **[Django Packages](https://djangopackages.org/)**: Directory of reusable apps, sites, tools, and packages for Django projects with side-by-side comparisons.
- **[Django Project](https://www.djangoproject.com/)**: Official website, documentation, release notes, and community hub for the Django web framework.
- **[Django Snippets](https://djangosnippets.org/)**: Community-contributed repository of reusable Django code snippets and patterns.
- **[Forum Django Project](https://forum.djangoproject.com/)**: Official Discourse forum for Django users and core contributors.
